# WhatsApp-only promotional card JPGs

Upload `PH-1.jpg`, `PH-2.jpg`, etc. to **this folder**.
These additional images will be served at `https://pixelhouse.lk/img/whatsapp-cards/PH-1.jpg` after deployment.

They are used ONLY by the separate `/whatsapp-catalog.csv` Meta feed.

**Never overwrite or edit `img/product` files.** The current website product photos and `/meta-catalog.csv` remain unchanged.

If a product has no custom card, the WhatsApp-only feed keeps its original image link instead of producing a broken link.
